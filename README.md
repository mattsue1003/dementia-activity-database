# 失智長輩活動資料庫

給社區據點、日照中心與居家照顧者使用：失智長輩也能參與的活動教案、YouTube／Shorts 影片與網頁資源。

**網站：** https://mattsue1003.github.io/dementia-activity-database/

## 內容

- **活動點子 60 個**：整理自「跨國失智症團康教案影片資料庫（350 部索引）」中沒有對應影片的條目，去除重複、改寫成在台灣可用的情境，附 YouTube／Google 搜尋與可參考的影片。
- **活動教案 26 份**：懷舊、音樂、感官、認知刺激、身體活動、生活任務、藝術手作、園藝、團康、節慶與代間、居家個別化。每份包含目標、準備物品、流程、輕／中／重度調整、帶領提醒、安全注意、觀察重點、相關影片與網頁、Google／YouTube 延伸搜尋。
- **影片資料庫 120 支**（Shorts 75、長片 45，來自 51 個頻道）：台灣 56、日本 41（含 REHA SHINE 精選 33）、韓國 11、美國 6、英國 2、加拿大 1、香港 1、其他英語影片 2。每支都用 YouTube 頁面確認存在、可嵌入，並看過畫面；只收坐姿或可改坐姿、規則簡單、與語言無關或可看畫面跟做的活動。
  - 我的最愛、已看過標記、自訂標籤、筆記
  - 我的清單：自建播放清單、排序、移出
  - ＋新增影片：貼上任何 YouTube／Shorts 網址加入自己的資料庫
  - 匯出／匯入備份（資料存在瀏覽器 localStorage）
- **網頁資源 16 筆**：台灣與國際機構的活動指引、實務文章，標註資料類型與研究做法。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 網站（單一檔案，資料已內嵌） |
| `lessons.json` | 教案內容（要修改教案就改這個） |
| `ideas.json` | 活動點子 |
| `resources.json` | 網頁資源 |
| `other_videos.json` / `other_meta.txt` | 台灣與各國頻道影片：中文說明、標籤／頻道、長度、觀看數、發布日（2026-10-17 擷取） |
| `rehashine_database.json` | REHA SHINE 影片資料，只採用 `build.py` 中 `REHA_KEEP` 名單 |
| `template.html` / `build.py` | 產生 index.html：`python3 build.py` |

## 說明

- 失智程度與場域標籤由玩法描述自動判斷，僅供挑選參考，帶領時請依長輩實際狀況調整。
- 影片版權屬於各頻道，本站只提供連結與嵌入播放；網頁資源內容以原網站為準。
